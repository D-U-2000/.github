# D&U 2000

We build software projects and document how we make decisions, verify behavior, and learn from delivery.

## Public overview

This page is the public organization entry point. It states purpose and links public work. Member onboarding prompts, access setup and private drafts belong in private repositories and Shortcut, not here.

## Current project

[Prism](https://github.com/D-U-2000/prism) is a financial systems sandbox with virtual money and simulated providers. Work begins with payment correctness, reconciliation and visible failure recovery. It is in early development.

Read the [Prism documentation](https://github.com/D-U-2000/prism/blob/main/docs/README.md) for scope, working standards and the first scenario.

Product-specific specifications stay in the product repository. Handbook contribution workflow is tracked in Shortcut sc-51; this overview only links repositories that already exist.

## How we work

Every planned change starts with a Shortcut story containing an owner, scope and acceptance criteria. Implementation and documentation are reviewed through pull requests. Checks provide evidence; completion requires acceptance against the story.

Engineering and business maintainers jointly review changes that cross technical and domain boundaries. Public issues are an intake channel; maintainers link accepted work to Shortcut before implementation.
